# 笔记博客

将个人笔记和发布的文章，翻译等内容都在该项目内

### 安装和启动

```
pnpm i
pnpm dev
```

### 打包

```
pnpm build
```

## 额外内容

- giscus 第三方开源评论模块
- github workflow 文档部署工作流
- tailwindcss tailwind 书写样式

### 部署

使用 github workflows 进行部署，详情可看 `.github\workflows\deploy-docs.yml`
